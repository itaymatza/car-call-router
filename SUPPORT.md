# Support

Use GitHub Issues for reproducible bugs and device-compatibility results. Before opening an issue:

1. Read the [FAQ](docs/FAQ.md), [authorization guide](docs/AUTHORIZATION.md), and
   [testing guide](docs/TESTING.md).
2. Reproduce the problem while parked with the current build.
3. Export only the app's redacted diagnostic data and review it before sharing.

Do not publish phone numbers, Bluetooth addresses, ADB serials, pairing records, signing material,
credentials, or unreviewed system dumps. Security, privacy, and safety vulnerabilities must follow
the private path in [SECURITY.md](SECURITY.md), not a public issue.

This is a volunteer beta project. No response-time or device-compatibility guarantee is offered.
